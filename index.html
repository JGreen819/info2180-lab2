Github builds on git by storing your repositories online, which makes it easy to post your work, and collaborate with other people. As my projects grow, so will my experience with Github and the git commands, like git branch, git pull, etc.

Committing and writing clear commit messages that describe what changed will make collaboration with others easier. A clear history makes it easier to locate mistakes and it's a good practice for working on a team. I'm also learning to use the .gitignore file to keep private information out of my repository, so only the code shared is visible.
